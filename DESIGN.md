# EasyTier dashboard entry and details

The homepage entry and detail cards follow the existing FlClash Material theme and CommonCard surface, 14 px corner radius and 16 px content spacing. They add no new colors, fonts or animations.

The homepage uses one compact row: EasyTier, runtime status, discovered node count and a chevron. It starts at 72 logical pixels with default text scaling and grows naturally with accessibility text. No node list, address or network detail is shown on the homepage. The entry is the last default dashboard grid item on HarmonyOS; the existing homepage editor can move, remove and re-add it. Saved positions are respected after a one-time migration adds the entry to existing layouts.

Tapping the entry opens an independent live detail page, including when EasyTier is disabled. The information hierarchy follows the [EasyTier HarmonyOS status page](https://github.com/FrankHan052176/EasyTier-ArkTS/blob/main/entry/src/main/ets/pages/hmrouter/StatusPage.ets): network and local IPv4 summary first, followed by all discovered nodes. A node card places hostname and selectable virtual IPv4 on the left and measured direct-link delay on the right. Direct/relay and protocol appear below, followed by available connection addresses in secondary text. The layout becomes two columns on wide screens; narrow screens and enlarged fonts wrap naturally. The count describes discovered nodes, not an immediate online guarantee. Relay delay is unavailable. Starting and stopped states hide old nodes; stale and unavailable data never presents a live delay or endpoint.

The detail page's settings action opens the existing configuration page. Its EasyTier IPv6 switch defaults off and is independent of FlClash IPv6; changes require stopping and restarting the VPN. Network behavior is unchanged by this presentation change.

Acceptance uses widget checks for compact height, navigation/back/settings, live updates, all-node visibility, state and overflow. Real Flutter PNG fixtures render the homepage using the actual Grid and CommonCard with standard dashboard content, plus detail pages in dark/light phone, wide, 320 px enlarged-text, stale, stopped and disabled layouts. Runtime system fonts remain unchanged; the CI-only CJK font supports readable screenshot evidence.
